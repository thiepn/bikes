# P14 — Urban U1: Dutch-Style Utility Bike

## Objective

Add Bike Atlas's first true everyday utility archetype and close the major catalog gap exposed by P13.

Urban U1 is not a Road R1 variant. It introduces a different product philosophy:

- upright position;
- step-through access;
- protected drivetrain;
- internal gearing;
- full-weather equipment;
- integrated cargo;
- everyday security and parking hardware.

## Identity

```text
ID         bike.urban.u1
Slug       urban-u1
Name       Urban U1
Archetype  dutch-utility-city
```

Urban U1 is a generic fictional Dutch-style utility bicycle, not a branded product.

## Semantic model

Urban U1 currently defines **42 semantic components** across 15 systems.

Distinctive utility components include:

- step-through frame;
- swept upright handlebar;
- ergonomic grips;
- internal-gear rear hub;
- single rear sprocket;
- full chain guard;
- full front and rear fenders;
- rear cargo rack;
- integrated front and rear lights;
- kickstand;
- frame lock;
- bell.

The internal-gear architecture intentionally has:

- no rear derailleur;
- no cassette.

## P13 Finder impact

Urban U1 receives a complete 10-trait Finder profile.

Strong traits:

- everyday paved riding;
- upright comfort/control;
- cargo utility;
- all-weather use;
- maintenance simplicity.

Weak traits:

- technical terrain;
- suspension capability;
- maximum paved-speed efficiency.

Current deterministic preset results:

```text
Fast road          → Road R1   100
Mixed exploration  → MTB M1     97
                     Urban U1   97
Trail riding       → MTB M1     99
Technical trail    → MTB M1     99
Daily utility      → Urban U1   98
```

Most importantly, **Daily utility no longer produces a catalog-gap warning**.

Before P14:

```text
Daily utility → Road R1 76 / closest current match / catalog gap
```

After P14:

```text
Daily utility → Urban U1 98 / strong current match
```

This is evidence that adding a new archetype changes product behavior rather than merely increasing model count.
