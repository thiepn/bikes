# P9 — Component Encyclopedia, Search, Cross-Linking & Knowledge Graph

## Objective

Make every Road R1 semantic component a useful knowledge object rather than only a selectable mesh.

P9 adds a complete component encyclopedia, full-text component search and cross-links derived from the existing mechanical, learning and Workshop graphs.

## Coverage

All **35 Road R1 semantic components** have an encyclopedia profile.

A profile includes:

- concise definition;
- functional explanation;
- common materials;
- compatibility/standard considerations;
- common symptoms worth investigating;
- aliases/search terms;
- curated related components.

The encyclopedia is independent of current mesh coverage.

The calibration rig currently exposes 27 parts in 3D, while the remaining entries are labeled **3D detail pending** and remain searchable/readable.

## Search

Explore now has an **Encyclopedia** entry next to Learn and Workshop.

Search indexes:

- component name;
- slug;
- system;
- tags;
- aliases;
- summary;
- function;
- materials;
- standards;
- common symptoms.

Examples:

```text
hub
bearing
creaking
carbon
brake
freehub
through axle
```

Search can also be filtered by bicycle system.

## Knowledge graph

P9 does not maintain a second manual graph for everything.

A component knowledge node is assembled from existing domain sources:

```text
Component
├─ encyclopedia profile
├─ Road R1 semantic metadata
├─ assembly-graph neighbors
├─ curated conceptual relations
├─ lessons that reference the component
├─ Workshop procedures that reference the component
└─ current 3D availability
```

Assembly neighbors are derived from P6 mechanical connections.

Lesson links are derived from P7 step focus/highlight/challenge references.

Workshop links are derived from P8 focus/highlight/removed-part references.

This keeps relationships synchronized as those systems grow.

## Component page

Selecting a component now opens a real encyclopedia view containing:

- summary;
- what it does;
- materials;
- compatibility/standards;
- common symptoms;
- connected and related parts;
- relevant lessons;
- relevant Workshop procedures;
- isolate/full-bike controls where 3D exists.

Connected component buttons navigate directly between knowledge nodes.

Lesson and Workshop links jump to the first step that references that component.

## Deep links

The existing component URL becomes the encyclopedia deep-link format:

```text
/?part=cassette
/?part=headset
/?part=bottom-bracket
/?part=front-derailleur
```

P9 removes the old limitation that only currently exposed calibration meshes could open from a component deep link.

## Validation

Repository validation now guarantees:

- knowledge base targets Road R1;
- exactly one profile per Road R1 semantic component;
- no duplicate profile IDs;
- every profile references a real component;
- every related component exists;
- no self-relations;
- required encyclopedia fields are populated.
