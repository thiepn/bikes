# P1 — 3D Engine, Camera, Lighting, Rendering & Asset Pipeline

## Objective

Prove the rendering architecture before production bicycle assets are introduced.

## Implemented

- Next.js App Router + strict TypeScript foundation.
- Full-viewport 3D-first product shell.
- React Three Fiber scene isolated from page/content code.
- ACES filmic tone mapping and sRGB output.
- Physically based materials and procedural studio lighting.
- Real-time contact shadows and adaptive DPR.
- Perspective camera with constrained orbit/zoom.
- Procedural calibration bicycle at real-world meter scale.
- Canonical +Y up / +Z forward / +X right coordinates.
- Bottom-bracket-centered production asset origin.
- BVH-ready raycasting.
- Reusable camera and rendering profiles.
- GLB node naming, LOD and asset-pipeline contract.

## Explicitly deferred

P1 does not implement the production Road R1 mesh, component selection, fly-to selection, X-ray, exploded views, lessons, repairs, KTX2/Meshopt runtime loading, accounts, or backend.

## Exit criteria

1. CI passes lint and production build.
2. Desktop and touch orbit/zoom work.
3. The scene reads as a neutral premium studio rather than a debug viewport.
4. Coordinate/scale/naming contracts are documented.
5. Rendering code is independent from Road R1 data.
