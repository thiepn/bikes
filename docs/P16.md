# P16 — Gravel G1: All-Road Archetype & Mixed-Surface Expansion

## Objective

Add Bike Atlas's fourth distinct bicycle family and close the mixed-surface ambiguity exposed after P15.

Gravel G1 occupies the engineering space between:

```text
Road R1
  fast paved efficiency
        ↓
Gravel G1
  all-road / mixed-surface balance
        ↓
MTB M1
  technical-trail control
```

It is not a Road R1 recolor and it is not a rigid mountain bike.

## Identity

```text
ID         bike.gravel.g1
Slug       gravel-g1
Name       Gravel G1
Archetype  gravel-all-road
```

Gravel G1 is a generic fictional all-road/gravel reference bike rather than a branded product.

## Semantic model

P16 defines **34 semantic components**.

Core architecture includes:

- rigid gravel frame and fork;
- flared drop handlebar;
- integrated drop-bar shift/brake controls;
- 700C mixed-surface tires;
- 1× crankset;
- single chainring;
- wide-range cassette;
- rear derailleur;
- hydraulic disc brakes;
- front/rear thru axles;
- frame utility mounts;
- fork utility mounts;
- downtube protection.

The reference is intentionally:

- 1×;
- rigid;
- derailleur-driven;
- wider-tired than Road R1;
- narrower-tired and less technical than MTB M1.

## P13 Finder impact

Gravel G1 receives a complete 10-trait Finder profile.

Strong traits:

- mixed-surface ability;
- long-distance efficiency;
- climbing;
- paved efficiency relative to off-road bikes;
- all-road comfort/control;
- light cargo / bikepacking flexibility.

Limits:

- less paved-speed focus than Road R1;
- far less technical-trail capability than MTB M1;
- less cargo/weather integration than Urban U1;
- no suspension travel.
