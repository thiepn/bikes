# P8 — Workshop Procedures, Tool Guidance & Step-by-Step Repair Simulation

## Objective

Turn the P6 assembly graph into practical, prerequisite-aware maintenance guidance.

P8 introduces a Workshop experience that shares the same Road R1 semantic model, camera system and inspection modes as Explore and Learn.

## Current procedures

1. **Remove and reinstall the rear wheel**
2. **Remove a cassette**
3. **Replace a derailleur chain**
4. **Inspect a disc brake**

The procedures are intentionally generic Road R1 workflows rather than manufacturer-specific service instructions.

## Procedure model

Each procedure declares:

- system;
- difficulty;
- expected duration;
- prerequisite procedures;
- required and optional tools;
- assumed assembly operations;
- ordered steps.

Each step declares:

- focus component;
- highlighted components;
- inspection mode;
- explosion depth;
- assembly operation when applicable;
- tools;
- warning;
- check before continuing;
- simulated removed/ghosted components.

## Mechanical dependency enforcement

Workshop uses the P6 assembly graph as mechanical truth.

A step linked to an assembly operation cannot complete unless all operation prerequisites are satisfied.

Example:

```text
release-rear-thru-axle
        ↓
remove-rear-wheel
        ↓
remove-cassette
```

The cassette procedure requires the rear-wheel procedure at catalog level and also declares the wheel-removal operations as assumed mechanical state.

The validator simulates each procedure's operations in order and rejects an invalid sequence.

## Visual simulation

The current calibration model cannot reproduce exact wrench motion or every fastener.

P8 therefore uses an explicit guided-simulation language:

- focus the relevant semantic component;
- highlight connected components;
- switch Normal / Systems / X-Ray / Exploded views;
- apply an authored explosion amount;
- ghost components representing a removed state.

Ghosting is viewer state and does not mutate the Road R1 model.

The final production GLB can later replace this with articulated removal paths without changing the procedure schema.

## Tools and safety

Procedures expose only tools relevant to the active step.

Warnings are prominent for issues such as:

- supporting a wheel while withdrawing the axle;
- protecting disc rotors from impact/contamination;
- not operating a hydraulic brake lever with the rotor removed;
- securely engaging cassette tools;
- correct chain routing.

Workshop guidance is educational and generic. Manufacturer torque values, component-specific reuse rules and safety-critical service specifications should come from the actual component manufacturer when branded/component-specific support is added.

## Progress

Workshop progress is stored locally:

```text
bike-atlas.workshop.v1
```

Per procedure:

- status;
- current/resume step;
- completed steps;
- completion time.

No backend is required.

## Deep links

```text
/?workshop=rear-wheel-removal&step=2
/?workshop=cassette-removal&step=3
/?workshop=chain-replacement&step=1
/?workshop=disc-brake-inspection&step=2
```

Direct links bypass catalog locking for sharing/debugging; normal Workshop navigation respects procedure prerequisites.

## Calibration expansion

P8 adds the rear thru axle to the procedural Road R1 rig.

It is now a semantic, selectable/focusable component with authored camera and explosion metadata.
