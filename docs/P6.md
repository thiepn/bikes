# P6 — Assembly Graph & Interactive Drivetrain Lesson

## Objective

Start the actual Bike Atlas learning system.

P6 introduces three deliberately separate layers:

1. **Mechanical truth** — the Road R1 assembly/dependency graph.
2. **Teaching sequence** — structured lesson steps referencing semantic components.
3. **Visualization** — a reusable drivetrain motion layer over the 3D bike.

This separation prevents future repair procedures, lessons, and animations from duplicating mechanical rules.

## Assembly graph

`content/assembly/road-r1.json` records component connections and executable dependency operations.

Current drivetrain/rear-wheel relationships include:

```text
frame
└─ bottom bracket
   └─ crankset
      └─ chainring
         └─ chain
            ├─ cassette
            │  └─ rear hub
            │     └─ rear wheel
            │        └─ rear thru axle
            └─ rear derailleur
```

Current operations include:

- release rear thru axle;
- remove rear wheel;
- disconnect chain;
- remove cassette;
- remove rear derailleur;
- remove crankset.

Prerequisites are explicit. For example, cassette removal requires rear-wheel removal, which requires releasing the thru axle.

The validator checks that all referenced components and operations exist and that the prerequisite graph has no cycles.

## First interactive lesson

**How a derailleur drivetrain works**

Five steps:

1. Rider input at the crank.
2. Chain transfer.
3. Gear ratio.
4. Rear-derailleur shifting.
5. Speed/ease trade-off plus a concept check.

Each lesson step specifies:

- focus component;
- highlighted components;
- inspection mode;
- drivetrain demo cadence;
- cassette gear index;
- explanatory text;
- optional interactive ratio controls;
- optional quiz.

The lesson therefore drives existing P3/P4 camera and highlighting infrastructure rather than inventing a separate viewer.

## Live drivetrain demonstration

P6 adds a calibration-grade motion layer:

- moving crank marker;
- moving chain flow markers;
- cassette rotational marker;
- selected sprocket highlight;
- derailleur shift-position indicator.

The final production Road R1 asset should later replace these calibration markers with actual articulated meshes while keeping the same `DrivetrainDemoState` API.

## Gear math

The lesson uses a declared demonstration setup:

- 50T front chainring;
- 11/13/15/17/19T sample rear sprockets;
- 2.105 m approximate 700c wheel circumference.

It computes:

```text
gear ratio = front teeth / rear teeth
wheel rpm = cadence × gear ratio
kinematic speed = wheel rpm × circumference
```

The displayed speed is explicitly kinematic gearing speed, not a claim about achievable real-world speed.

## Lesson routing

The lesson can be linked directly:

```text
/?lesson=drivetrain-basics&step=1
/?lesson=drivetrain-basics&step=4
```

Direct lesson links bypass the cinematic intro.

## Interaction

The lesson panel supports:

- previous/next step;
- direct step navigation;
- run/pause drivetrain;
- rear-sprocket changes on ratio/shifting steps;
- live ratio, wheel-rpm and kinematic-speed calculations;
- final understanding check;
- exit back to Explore.

## Production boundary

P6 does not pretend the calibration geometry is a physically exact drivetrain.

The learning architecture is now established; final mechanical articulation still depends on P2B's production Road R1 asset and later deep component models.
